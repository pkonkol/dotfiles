# dotfiles

- Symlinki robi Dotter według `.dotter/global.toml`: `just deploy` pokazuje zmiany, `just deploy --apply` je wykonuje.
- `pk-skills/` to osobne repo git, gitignorowane tutaj: plugin Claude Code `pk`, reguły `~/.claude/rules/pk-*.md`.
  Praca nad pk: pliki i git w `pk-skills/` (`git -C pk-skills …`), zasady w `pk-skills/CLAUDE.md`, recepty przez `just pk <recepta>`.
